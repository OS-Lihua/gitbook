# Polymarket 原理

Polymarket 是 在 polygon 上部署的一个基于事件的交易平台。

用户通过判断一件事情发生的概率去下注，通过事件发生的真正概率去获得盈利。

大部分赌博平台都是通过提前下注，在事件发生后给出确定性的结果，比如我们常常知道的体育赛事的博彩，赌球；我们提前下注自己看好的球队，在比赛结束后，我们就可以获得对家的奖池。

#### Polymarket 不一样

Polymarket 通过它特殊的机制，让用户不仅可以在事件真正发生后才盈利，而且可以在事件发生的概率波动中交易，也就是交易概率，这就非常有意思了。\


***

我们这里定义3 个主要角色

1. 赌徒
2. 盘主
3. 平台





世界上大部分生意盈利的本质都是：

此树是我栽，此路是我开，要想从此过，留下买路财。

Polymarket 也不例外。
